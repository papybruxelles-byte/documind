# Comment utiliser Signataire Intelligent

## Qu’est-ce que Signataire Intelligent ?

Signataire Intelligent aide votre organisation à recevoir, comprendre, classer et suivre ses documents.

Au lieu de chercher manuellement une facture, un contrat ou un courrier, vous pouvez demander à Signataire de retrouver l’information importante. L’application vous indique aussi les documents qui demandent une action.

Chaque document suit un parcours. Par exemple, une facture peut être reçue, vérifiée, approuvée, programmée pour paiement, payée puis archivée.

## Comment commencer ?

### 1. Ajouter un document

Vous pouvez :

- importer un fichier depuis votre ordinateur ;
- prendre une photo avec votre téléphone ou votre caméra ;
- numériser un document papier.

Signataire accepte notamment les PDF, documents Word, images et fichiers texte.

### 2. Laisser Signataire analyser le document

Après l’importation, Signataire lit le document et essaie de reconnaître son type : facture, contrat, document d’assurance, courrier administratif ou autre.

Il prépare ensuite :

- un résumé simple ;
- les dates importantes ;
- les montants détectés ;
- le nom de l’émetteur ou du fournisseur ;
- l’action qui semble nécessaire.

### 3. Vérifier les informations

L’intelligence artificielle fait gagner du temps, mais une personne doit toujours vérifier les informations importantes avant une décision, un paiement ou un envoi officiel.

Ouvrez le document, comparez les informations extraites avec l’original, puis corrigez ou complétez le dossier si nécessaire.

### 4. Agir sur le document

Selon le type de document, vous pouvez :

- l’assigner à une personne ou à un service ;
- l’approuver ;
- ajouter une note ;
- programmer un rappel ;
- poser une question à l’IA ;
- marquer une facture comme payée ;
- consulter le document original.

### 5. Consulter le Centre d’actions IA

Le Centre d’actions présente les documents qui demandent votre attention. Vous pouvez voir, par exemple :

- les factures à approuver ;
- les factures proches de leur échéance ;
- les contrats qui expirent bientôt ;
- les documents assignés qui n’ont pas encore été examinés.

Vous pouvez également poser des questions simples :

- « Qu’est-ce qui demande mon attention aujourd’hui ? »
- « Montre les factures impayées supérieures à 1 000 €. »
- « Quels contrats expirent ce mois-ci ? »
- « Montre les documents en attente au service comptable. »

## Pourquoi Signataire est important pour une entreprise privée

Une entreprise privée reçoit de nombreux documents : factures, devis, commandes, contrats, preuves de livraison et demandes de clients.

Signataire Intelligent permet de :

- réduire le temps passé à rechercher et lire les documents ;
- éviter les paiements en retard ;
- mieux suivre les validations internes ;
- détecter plus facilement les factures en double ;
- rapprocher une commande, une livraison et une facture ;
- faciliter le travail entre les équipes comptables, juridiques et opérationnelles ;
- conserver une trace claire des actions effectuées.

Le résultat est simple : moins d’oublis, moins d’erreurs et des décisions plus rapides.

## Pourquoi Signataire est important pour un organisme public

Une administration ou une entreprise publique traite des courriers, demandes citoyennes, contrats, factures, dossiers administratifs et documents réglementaires.

Signataire Intelligent permet de :

- classer automatiquement les documents reçus ;
- transmettre chaque dossier au bon service ;
- repérer les délais de réponse ;
- suivre l’avancement d’une demande ;
- retrouver rapidement un document ou une information ;
- améliorer la continuité du travail entre les services ;
- limiter les dossiers oubliés ou traités en retard.

Il aide ainsi les agents à mieux suivre les dossiers et à offrir un service plus rapide et plus transparent.

## Bonnes pratiques

- Vérifiez toujours les montants, dates et noms avant une action importante.
- Assignez chaque document à une personne responsable.
- Utilisez les rappels pour les paiements, renouvellements et réponses attendues.
- Ajoutez des notes courtes et utiles pour faciliter le travail de l’équipe.
- Limitez l’accès aux documents confidentiels aux personnes autorisées.
- Archivez les dossiers terminés pour garder un espace de travail clair.

## En résumé

Signataire Intelligent ne sert pas seulement à stocker des fichiers. Il transforme chaque document en travail organisé et suivi.

Le principe est simple :

**Ajouter → Comprendre → Vérifier → Assigner → Agir → Suivre → Archiver**

Cela permet aux organisations privées et publiques de gagner du temps, de réduire les erreurs et de mieux respecter leurs engagements.
